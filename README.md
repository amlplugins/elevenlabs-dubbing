# @amlplugins/elevenlabs-dubbing

Native `@elevenlabs/elevenlabs-js` SDK re-exported under the `@amlplugins` namespace.

> ElevenLabs Dubbing — automated translation + lip-sync dubbing for video across 32+ languages.

## Install

```bash
npm install @amlplugins/elevenlabs-dubbing
```

## Use

```ts
import { /* named exports from @elevenlabs/elevenlabs-js */ } from "@amlplugins/elevenlabs-dubbing";
// or
import sdk from "@amlplugins/elevenlabs-dubbing";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
